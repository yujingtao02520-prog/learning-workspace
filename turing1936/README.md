# 论可计算数 · 1936 —— 图灵论文双语精读本

A. M. Turing, *On Computable Numbers, with an Application to the Entscheidungsproblem*
（论可计算数及其在判定问题上的应用）
Proc. London Math. Soc. s2-42 (1936–37), pp. 230–265；更正见 s2-43 (1937), pp. 544–546。

## 这是什么

图灵 1936 年论文的**全文中英对照 + 逐段解读笔记 + 与现代计算机科学对照**的 HTML 读本。
据调查（2026-09），此组合无正式出版物质提供：中文世界只有 Petzold《图灵的秘密》（转述式解读、
不含原文）、尼克《理解图灵》（解读对象是 1950 年论文）与零散博客译文。本项目填补此空白。

图灵 1954 年逝世，论文著作权已进入公有领域；英文底本为伦敦数学会授权的全文转录
（abelard.org），并以杜克大学、弗吉尼亚大学等处存档的期刊影印件逐节校勘
（abelard 转录在 §2 有渲染缺漏，该节以影印本复核录入）。

## 精读页的版式约定

- 每个自然段一个 `.pair`：左英文（底本原文）右中文（原创翻译），段号 `¶ 1.2a`。
  原文超长段落按语义切块（如 §1 第二段 → 1.2a–1.2d），并在页首注明。
- 原刊页码以居中小字（`p. 232`）标在对应段落之间。
- 三类批注卡：`解读`（段落本身说什么）、`现代对照`（对应现代 CS 概念）、`背景`（历史人物脉络）。
- 术语悬停：`m-configuration` 等虚线下划线词悬停显示中译与说明。
- 章末有"本节小结"术语表；顶栏可切换 对照/原文/中文 三种视图。

## 译名约定（核心）

| 原文 | 本站译名 | 备注 |
|---|---|---|
| m-configuration | m-格局 | 也译 m-配置 |
| configuration | 格局 | （状态, 被扫描符号）二元组 |
| scanned square | 被扫描方格 | 也译注视方格 |
| figures | 数码 | 输出的 0/1；限制为 0/1 是为表示唯一性 |
| circular / circle-free | 循环的 / 非循环的 | ≠死循环！见 §2 ¶2.4 注 |
| S.D / D.N | 标准描述 / 描述数 | 源代码 / 可执行编码 |
| universal machine | 通用计算机器 | 即通用图灵机 |
| F/E-squares | F-方格 / E-方格 | 输出区 / 可擦草稿区 |
| Entscheidungsproblem | 判定问题 | 德文原词保留 |

完整译名表见 `index.html`。
