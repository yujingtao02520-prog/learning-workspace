本节速览

图灵交付了历史上第一批完整的程序。机器 Ⅰ 只有寥寥几个 m-格局，在空白纸带上打印 0101010101…，即数 1/3 的（0/1 数码）十进制展开——它的转移表就是世上第一份程序清单。机器 Ⅱ 打印 0010110111011110…：用 0 分隔、每组渐多的 1。两台机器都完整可运行，图灵逐一推演它们的逐步动作给读者看。

本节同时定下两件影响至今的规范：①转移表的标准形式——四列：m-格局 │ 被扫描符号 │ 操作 │ 最终 m-格局；一张表 = 一台机器 = 一个程序。②F-方格 / E-方格——纸带相间分区：F-方格（figures）承载不可擦的数码输出，E-方格（erasable）承载可擦的草稿：输出区与工作区的第一次显式分离。

现代对照：转移表 ↔ 汇编程序清单；机器 Ⅰ ↔ 计算机科学版的 "Hello, World"；F/E-方格分离 ↔ 代码段与数据段、stdout 与堆内存的分界。

本节关键概念一句话
machine Ⅰ打印 010101…（= 1/3）的第一台例机
machine Ⅱ打印 0010110111011110… 的第二台例机
standard form of table四列转移表：m-格局 / 被扫描符号 / 操作 / 最终 m-格局
F-squares / E-squares数码方格（不可擦输出区）/ 草稿方格（可擦工作区）
