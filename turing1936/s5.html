Enumeration of Computable Sequences可计算序列的枚举

本节速览

全文的枢纽一步：机器可以变成数。每台机器由一张有限的标准表完全描述；表的每一行按固定规则编码为几个字母（D 加数字标记 m-格局，L、R、N、P、E 等标记操作，分号分行），得到一个字符串——标准描述 S.D（standard description）；再把七个字母逐一替换为 1–7 的数字，得到一个自然数——描述数 D.N（description number）。于是：机器 ↦ 整数，全体机器可排成无穷列表 1(1), 1(2), 1(3), …，全体可计算序列随之可数。

这一步同时是三件事：①"程序即数据"的数学化——机器的描述本身可以写在另一台机器的纸带上（§6 通用机的全部前提）；②哥德尔编码的图灵版——把语法对象映射为自然数；③§8 对角线论证的地基——"第 n 台机器"这个说法只有在此之后才有意义。

现代对照：S.D ↔ 源代码文本；D.N ↔ 可执行文件字节序列；"程序可数，问题无穷" ↔ 现代课堂上"几乎所有函数不可编程"的标准论证；对程序做编号排序，也是编译器、病毒签名、包管理器的日常操作——万物皆数，1936 年已见雏形。

本节关键概念一句话
standard description (S.D)机器表的字母编码——"源代码"
description number (D.N)把 S.D 的字母换成数字所得的自然数——"可执行文件"
1(n)描述数为 n 的那台机器；机器从此可编号、可排序
complete configuration完全格局（带面快照+状态+头位），编码的基本对象
