半页纸，五组定义，全文的地基：a-机器（确定性）、c-机器（交互性，本文弃用）、计算机器（输出 0/1）、循环 / 非循环（产出性）、可计算序列 / 可计算数（最终研究对象）。本节是"1936 术语 → 现代术语"换算表最密集的一页，每条定义的批注里都给出对应。

术语警报：circular（循环的）≠ 死循环！见 ¶ 2.4 的解读。另：原刊目录把第三小节写作 Circle and circle-free numbers，正文标题为 Machines，本读本从正文标题。

¶ 2.1 · Automatic machines

If the motions of a machine are wholly determined by the configuration we shall call the machine an automatic machine (or a-machine).

如果一台机器的运动完全由格局所决定，我们就称它为「自动机器」（automatic machine，或 a-机器）。

解 读

"完全"（wholly）一词兑现了 §1 埋下的伏笔：§1 说格局决定的是"可能的行为"，正是因为存在下一段那种只被"部分决定"的机器。定义自动机器 = 把确定性写进定义：同样的格局，永远同样的下一步。全文此后凡说"机器"，默认指 a-机器。

现代对照

即确定性图灵机（DTM），一切计算理论的默认模型。状态转移系统的公理化表述（初态、转移关系、终态）与这里逐字对应：转移关系是函数而非关系，就是"wholly determined"。

¶ 2.2 · Choice machines

We might, for some purposes, use machines (choice machines, or c-machines) whose motion is only partially determined by the configuration (hence the use of the word "possible" in §1). When such a machine reaches one of these ambiguous configurations, it cannot go on until some arbitrary choice has been made by an external operator. This would be the case if we were using machines to deal with axiomatic systems. In this paper I deal only with automatic machines, and will therefore often omit the prefix a-.

在某些用途中，我们可能会使用其运动只部分地由格局决定的机器（「选择机器」，choice machine，或 c-机器）——这正是 §1 中要使用「可能」一词的原因。当这种机器到达某个含混格局（ambiguous configuration）时，它无法继续运行，除非由外部操作者做出某种任意的选择。如果我们用机器来处理公理系统，就会出现这种情况。本文只讨论自动机器，因此常将前缀 a- 省去。

解 读

图灵设想 c-机器的用途是"处理公理系统"：机器在证明搜索中走到岔路口——用哪条公理、走哪条推理规则——必须有人替它选。注意图灵的做法：提出它、说明用途、然后明确声明本文不碰它。这是全文唯一出现"交互"的地方，却埋下一条重要的暗线（见右卡）。

现代对照

c-机器有三条现代血脉：①非确定性图灵机（NDTM）——但语义不同：NDTM 自动并行地做所有选择，c-机器等人选；②交互式计算——外部操作者即用户/环境，在线算法、对话式 AI 都是"运动部分由格局决定"的机器；③最直接的一脉：图灵 1939 年论文《基于序数的逻辑系统》把 c-机器发展成预言机机器（oracle machine）——相对可计算性与图灵度理论的起点。

¶ 2.3 · Computing machines

If an a-machine prints two kinds of symbols, of which the first kind (called figures) consists entirely of 0 and 1 (the others being called symbols of the second kind), then the machine will be called a computing machine.

如果一台 a-机器打印两类符号，其中第一类（称为「数码」）完全由 0 和 1 组成（其余的称为「第二类符号」），那么这台机器就称为「计算机器」（computing machine）。

解 读

两个容易错过的细节。①为什么数码只有 0 和 1，而不是 0 到 9？不只是"二进制"：图灵的数码是十进制展开中的一位，限制每位只能取 0/1，是为了排除 0.d999… = 0.(d+1)000… 型的表示二义性——小数表示唯一，"机器算出的数"才良定义。②"两类符号"= 输出字母表与工作字母表的分离：数码是成果，第二类符号是草稿。任何有限字母表的输出都能编码成 0/1 序列，所以这个限制不损失一般性。

现代对照

输出字母表 Σout 与带字母表 Γ 的分离；0/1 序列作为最通用介质的现代版就是二进制与比特流。把一切输出归约为 0/1 序列，也预示了"任何可计算对象（函数、谓词、图、程序本身）都能编码为自然数/比特串"这一当代计算理论的默认操作。

¶ 2.4 · Circular & circle-free

If a computing machine never writes down more than a finite number of symbols of the first kind, it will be called circular. Otherwise it is said to be circle-free.

如果一台计算机器写下的第一类符号从不超过有限个，它就称为「循环的」（circular）；否则称为「非循环的」（circle-free）。

解 读

全文最容易被误读的一组定义。①"循环的"包括两种死法：陷入死循环（转个不停却不再打印数码），或干脆停住不动——共同点是数码产出有限；②"非循环的"是好事：它永远不断打印新数码，产出无限完整的小数展开——与"死循环"的贬义恰好相反；③为何定义可计算数必须用非循环机器？因为实数的小数展开无限长，一台打三个数码就死的机器给不出确定的数。这条定义是 §8 不可判定定理的靶心：图灵证明的正是"没有机器能判定任意机器是否非循环"——它是停机问题的第一个严格形态。

现代对照

circle-free ↔ 计算全函数（total function）的机器 / 处处产出输出的流式转换器；circular ↔ 部分函数（partial function）在某输入上发散（diverge）。经典对位：HALT = {⟨M⟩ : M 最终停机} 是不可判定的；图灵 1936 年证明的命题与之等价。现代可计算分析学改用"任意精度逼近"定义可计算实数（Type-2 可计算性），与图灵的"无限打印小数位"版本等价，但更便于数值计算使用。

¶ 2.5 · Computable sequences & numbers

If a machine is circle-free and is supplied with a blank tape, then the sequence of figures which it prints will be called the sequence computed by the machine. A number computed by a machine is defined to be the number whose decimal representation is obtained from that sequence by prefacing it with a decimal point. A sequence is computable if it is computed by some circle-free machine. A number is computable if it differs by an integer from a number computed by a circle-free machine.

如果一台机器是非循环的，并给它一条空白纸带，那么它打印出的数码序列就称为「由这台机器计算的序列」。由机器计算的数定义为：在该序列前面加上一个小数点所得到的那个数。一个序列是可计算的，如果它由某台非循环机器所计算。一个数是可计算的，如果它与某台非循环机器所计算的数只相差一个整数。

解 读

定义链在此闭合：非循环机器 →（空白纸带）→ 无限数码序列 →（加小数点）→ [0,1) 中的数 →（平移整数）→ 一切实数。三个技术细节：①空白纸带：机器无输入——它要算的数全部"写死"在机器表里，程序即数据；②加小数点：序列 010101… 变成 0.010101…（十进制），配合 ¶ 2.3 的 0/1 限制，数的表示唯一；③相差一个整数：机器直接定义的是小数部分，整数部分单独处理——可计算性对整数平移当然不变。

现代对照

现代课程的语言：可计算序列 = 递归可枚举的 0/1 序列中能被全函数型机器打印者；可计算实数 = 存在算法以任意给定精度输出其有理逼近。图灵版与现代版等价，但起点不同：图灵从"打印十进制展开"出发，现代数值分析偏好"柯西逼近快于任意给定速率"——后者避免了"打印第 n 位要等指数久"的病态情形，这个差异正是后来可计算分析（computable analysis）课程的入门话题。
